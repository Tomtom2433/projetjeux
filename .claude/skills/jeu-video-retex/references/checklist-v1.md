# Avant de montrer le jeu à de vrais joueurs

## Bloquant
- [ ] Une partie complète jouée par un humain sur téléphone, du début à la fin.
- [ ] Son écouté : ambiance, musique, bruitages, volumes par défaut.
- [ ] Fluidité mesurée sur un téléphone de milieu de gamme.
- [ ] Défaite claire, avec moyen de rejouer ; niveaux de difficulté.
- [ ] Tutoriel impossible à rater, relançable, sans impasse.

## Nécessaire
- [ ] Mise en page portrait et paysage vérifiée, interface réductible.
- [ ] Taille du texte réglable ; aucune information portée par la couleur seule.
- [ ] Manuel, guides d'écran, conseils à la première occurrence.
- [ ] Raisons de rejouer : variations par partie, objectifs secondaires, succès, statistiques.
- [ ] Textes hors du code si une autre langue est envisagée.

## Distribution
- [ ] Déploiement automatique depuis la branche principale.
- [ ] Erreurs conservées sur l'appareil et rapport copiable ; aucun envoi sans accord.
- [ ] Écran « À propos » : crédits, confidentialité, outils de génération utilisés.
- [ ] Licences des images et modèles générés vérifiées pour l'usage prévu.
- [ ] Page de présentation, captures, icône.
